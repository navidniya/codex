# Heartbeat Checklist - QA Analyst

On each heartbeat cycle:

1. [ ] Check assigned issues from Lead Architect
2. [ ] Pick the highest priority untested area
3. [ ] Analyze existing test coverage for that area
4. [ ] Identify missing test scenarios and edge cases
5. [ ] Document proposed test cases with clear assertions
6. [ ] Report findings back to Lead Architect
7. [ ] Store analysis notes in memory for continuity
