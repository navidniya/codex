# Heartbeat Checklist - Code Reviewer

On each heartbeat cycle:

1. [ ] Check assigned issues from Lead Architect
2. [ ] Pick the highest priority unreviewed module
3. [ ] Scan for code smells and anti-patterns
4. [ ] Document findings with file paths and line numbers
5. [ ] Rate each issue by severity
6. [ ] Report findings back to Lead Architect
7. [ ] Store analysis notes in memory for continuity
