# Heartbeat Checklist - Security Auditor

On each heartbeat cycle:

1. [ ] Check assigned issues from Lead Architect
2. [ ] Pick the highest priority unaudited component
3. [ ] Scan for OWASP Top 10 vulnerabilities
4. [ ] Check dependencies for known CVEs
5. [ ] Review authentication and data handling patterns
6. [ ] Document findings with severity ratings
7. [ ] Report critical issues immediately to Lead Architect
8. [ ] Store analysis notes in memory for continuity
