# Heartbeat Checklist - Documentation Analyst

On each heartbeat cycle:

1. [ ] Check assigned issues from Lead Architect
2. [ ] Pick the highest priority undocumented area
3. [ ] Audit existing docs for that area
4. [ ] Identify gaps between code and documentation
5. [ ] Draft documentation improvement suggestions
6. [ ] Report findings back to Lead Architect
7. [ ] Store analysis notes in memory for continuity
