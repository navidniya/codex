# Heartbeat Checklist - Lead Architect

On each heartbeat cycle:

1. [ ] Read the company goal and current priorities
2. [ ] Check status of all delegated tasks
3. [ ] Review completed work from direct reports
4. [ ] Identify blocked agents and unblock them
5. [ ] Update the analysis progress tracker
6. [ ] Reprioritize backlog if new findings change urgency
7. [ ] Write a brief status summary for the board
